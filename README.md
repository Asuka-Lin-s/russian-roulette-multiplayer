# 🔫 俄罗斯轮盘 - 多人联机版

与好友一起玩俄罗斯轮盘，支持 2-6 人对战。

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动服务器
```bash
npm start
# 或双击 start.bat
```

### 3. 打开游戏
浏览器访问 `http://localhost:3000`

## 游戏流程

1. **创建房间** - 输入昵称，点击"创建房间"
2. **分享房间号** - 把6位房间号发给朋友
3. **朋友加入** - 朋友输入房间号加入
4. **准备** - 所有人点击"准备"
5. **开始游戏** - 房主点击"开始游戏"
6. **轮流开枪** - 轮到你时点击"扣动扳机"

## 游戏规则

- 6个弹仓，1颗子弹，随机位置
- 每人轮流扣动扳机
- 中弹者死亡，最后存活者获胜
- 每轮会显示当前死亡概率

## 让朋友加入（异地联机）

### 方案1：同一WiFi（最简单）
1. 查看你的内网IP：`ipconfig`，找 `IPv4 地址`
2. 朋友访问 `http://你的IP:3000`

### 方案2：异地联机（需要内网穿透）
使用以下工具之一：
- **花生壳** - https://hsk.oray.com
- **Ngrok** - `ngrok http 3000`
- **向日葵** - 远程桌面共享

### 方案3：部署到服务器
如果有云服务器，把代码传上去运行，大家访问服务器IP即可。

## 功能特性

- ✅ 创建/加入房间
- ✅ 实时同步游戏状态
- ✅ 聊天功能
- ✅ 游戏历史记录
- ✅ 死亡概率计算
- ✅ 音效反馈
- ✅ 支持 2-6 人

## 技术栈

- Node.js + Express
- WebSocket (ws)
- 原生 JavaScript

## 注意事项

- 需要 Node.js 14+ 环境
- 防火墙需要放行 3000 端口
- 游戏数据仅存内存，重启服务器会清空
